# Презентации Slidev

В корне проекта общие зависимости и команды. У каждой презентации своя папка в `decks/` со слайдами, стилями и макетами. Для изображений можно добавить `public/` в папке презентации.

## Запуск

```bash
yarn dev -- <project_name> --open
```

## Правки и проверка

| Команда                                  | Действие                                                |
| ---------------------------------------- | ------------------------------------------------------- |
| `yarn new -- my-next-talk`            | Создать папку новой презентации из шаблона              |
| `yarn format -- qualitative-research` | Отформатировать Markdown Slidev, Vue и CSS              |
| `yarn check -- qualitative-research`  | Проверить формат, сборку и выход содержимого за границы |
| `yarn pdf -- qualitative-research`    | Сохранить PDF в `dist/qualitative-research.pdf`         |
