# Where’s Fluffymon? — Slidev

Светлая редакция черновой презентации для защиты архитектурной каты. 16:9, 16 слайдов. Содержание, TODO и Mermaid-диаграммы редактируются в `slides.md`.

## Запуск

Node.js 22+:

```sh
npm install
npm run dev
```

`npm run build` — сборка сайта. Для PDF-экспорта может потребоваться `npm install -D playwright-chromium`, затем `npm run export`.

## Макеты

- `ff-hero`: обложка с SVG-схемой (параметр `image`) или заключение (`closing: true`).
- `ff-base`: текст, таблицы, требования и драйверы.
- `ff-split`: две колонки; правую определяет `::right::`.
- `ff-diagram`: архитектурные диаграммы Mermaid.
- `ff-adr`: решение, альтернативы и последствия.

`section` — название раздела. `FfPanel` — простой текстовый блок с горизонтальной линией, без карточного оформления. Общая визуальная система задана в `style.css`. Фон #FAFAF7, текст #202822, акцент #225D49. `public/visuals` содержит две вручную построенные SVG-схемы, а не нейросетевые изображения. Схемы иллюстрируют типы геоданных и принцип AR; это не скриншоты продукта.

## Статус

Содержание предварительное: TODO и статусы ADR сохранены. Среда Slidev не установлена в контейнере, а npm registry недоступен. Сборку Slidev и окончательную геометрию Mermaid необходимо проверить после установки зависимостей.
